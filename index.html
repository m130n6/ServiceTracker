Pengaturan Database

Aplikasi ini bisa menyimpan data ke Google Sheets. Masukkan URL Web App dari Google Apps Script Anda. Jika dikosongkan, aplikasi akan berjalan dalam mode simulasi (Local Storage).

Cara mendapatkan URL:

  1. Buat Google Sheet dengan header sesuai form.
  2. Buka Ekstensi > Apps Script.
  3. Paste kode Code.gs yang disediakan AI.
  4. Deploy sebagai Web App (Akses: Siapa saja).
  5. Copy URL dan paste di atas.
